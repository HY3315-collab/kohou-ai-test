# 広報AI評価用 架空コーポレートサイト

GitHub Pagesでそのまま公開できる静的サイトです。広報AIのURL巡回・文章チェック評価用に、誤字、表記ゆれ、矛盾、文章品質上の問題を意図的に混ぜています。

## GitHub Pagesへの公開手順

1. GitHubで新しいPublic Repository（例: `kohou-ai-test`）を作成します。
2. この4ファイルをリポジトリ直下に配置します。
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. GitHubの `Settings` → `Pages` を開きます。
4. `Build and deployment` の Source を `Deploy from a branch` にします。
5. Branch を `main`、フォルダを `/(root)` にして Save します。
6. 公開後に表示されるURLを広報AIへ入力します。

例: `https://YOUR-USER-NAME.github.io/kohou-ai-test/`

## 注意

このサイトは意図的に誤った文章・表記・ダミーリンクを含みます。本番情報や機密情報は追加しないでください。

右下の「評価用 正解表」で仕込み項目を確認できます。AIに評価させる際は正解表を閉じて使用してください。
